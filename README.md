🚀 راهنمای نصب روی سرور

پیش‌نیازها

- Ubuntu 22.04 یا 24.04
- دسترسی Root
- دامنه متصل به سرور
- گواهی SSL معتبر
- توکن ربات تلگرام از BotFather

۱. نصب ابزارهای موردنیاز

apt update
apt install -y unzip wget curl php-cli

۲. دریافت سورس پروژه

cd /root
wget -O iranveto_bot.zip https://github.com/amirsokt/iranvito_bot/raw/refs/heads/main/iranveto_bot.zip

۳. استخراج فایل‌ها

unzip -o iranveto_bot.zip
cd /root/iranveto_bot

۴. اجرای نصب‌کننده

chmod +x install.sh
bash install.sh

در مراحل نصب، اطلاعات موردنیاز مانند دامنه و تنظیمات ربات را وارد کنید.

۵. تنظیمات ربات

فایل تنظیمات:

"/var/www/bot/config.php"

اطلاعات موردنیاز:

- توکن ربات
- نام کاربری ربات
- شناسه عددی مدیر
- رمز امنیتی SECRET

توجه: مقادیر واقعی را در GitHub منتشر نکنید.

🔄 به‌روزرسانی پروژه

برای دریافت نسخه جدید، ابتدا از تنظیمات و اطلاعات مهم نسخه پشتیبان بگیرید.

دریافت نسخه جدید:

cd /root
wget -O iranveto_bot.zip https://github.com/amirsokt/iranvito_bot/raw/refs/heads/main/iranveto_bot.zip

استخراج در پوشه جداگانه:

mkdir -p /root/iranveto_update
unzip -o iranveto_bot.zip -d /root/iranveto_update

پس از دریافت نسخه جدید، فایل‌های تغییرکرده را با نسخه نصب‌شده تطبیق دهید و با حفظ "config.php"، اطلاعات "data" و "cache" به‌روزرسانی کنید.

نکته: فایل‌های نسخه جدید را بدون بررسی مستقیم روی نسخه فعال کپی نکنید.

⚙️ راه‌اندازی و مدیریت

شروع ربات

در تلگرام دستور زیر را ارسال کنید:

/start

نمایش قیمت‌ها

/prices

ورود به پنل مدیریت

/panel

این دستور را با حساب مدیر ربات ارسال کنید.

دریافت شناسه تلگرام

/id

فعال‌سازی وب‌هوک

پس از تنظیم فایل "config.php"، آدرس راه‌اندازی وب‌هوک به شکل زیر است:

https://YOUR-DOMAIN/bot.php?setup=YOUR-SECRET

به‌جای "YOUR-DOMAIN" دامنه خود و به‌جای "YOUR-SECRET" مقدار خصوصی تنظیم‌شده در فایل کانفیگ را قرار دهید.

پاسخ موفق باید شامل "Webhook was set" باشد.

بررسی وضعیت نصب

https://YOUR-DOMAIN/health.php?key=YOUR-SECRET

پس از پایان تست، فایل "health.php" را از دسترس عمومی خارج یا حذف کنید.
