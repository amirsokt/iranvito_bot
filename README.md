🇮🇷 IranVito Change | ایرانویتو چنج

ربات هوشمند اطلاع‌رسانی و نمایش قیمت بازارهای مالی و ارز

ایرانویتو چنج یک پروژه تلگرامی با هدف ارائه اطلاعات و قیمت‌های بازارهای مالی، ارز، طلا و رمزارزها در محیطی ساده، سریع و کاربردی است.

این پروژه با ترکیب ربات تلگرام و Mini App تلاش می‌کند دسترسی کاربران به اطلاعات بازار را آسان‌تر کند.

✨ امکانات ربات

- 📊 نمایش قیمت‌های بازار و دارایی‌های مختلف
- 💱 نمایش نرخ ارزهای مختلف
- 🪙 نمایش قیمت طلا، سکه و فلزات گران‌بها
- ₿ نمایش اطلاعات و قیمت رمزارزها
- 🌍 نمایش اطلاعات ارزهای جهانی
- 📈 نمایش نمودار تغییرات قیمت
- 🧮 ماشین‌حساب محاسبه قیمت
- 🏛 رابط کاربری گرافیکی از طریق Telegram Mini App
- ⚙️ پنل مدیریت ربات
- 🔄 به‌روزرسانی اطلاعات قیمت‌ها

📱 مینی‌اپ تلگرام

ایرانویتو چنج علاوه بر دستورات متنی، دارای رابط کاربری Mini App است که از داخل تلگرام قابل استفاده است.

در مینی‌اپ امکاناتی مانند موارد زیر در دسترس قرار می‌گیرد:

- مشاهده تابلو قیمت‌ها
- دسته‌بندی بازارها
- جست‌وجوی دارایی‌ها
- مشاهده جزئیات قیمت
- نمودار تغییرات
- ماشین‌حساب تبدیل و محاسبه قیمت

🤖 دستورات ربات

دستور| توضیحات
"/start"| شروع کار با ربات
"/prices"| نمایش قیمت‌های بازار
"/menu"| نمایش منوی اصلی
"/panel"| ورود به پنل مدیریت
"/id"| نمایش شناسه عددی تلگرام

🚀 نصب و راه‌اندازی

پیش‌نیازها:

- سرور لینوکسی
- PHP
- Nginx
- افزونه‌های موردنیاز PHP
- توکن ربات تلگرام از BotFather
- دامنه متصل به سرور با HTTPS

مراحل کلی نصب:

1. دریافت سورس پروژه
2. تنظیم دامنه و وب‌سرور
3. ساخت فایل تنظیمات از روی "config.example.php"
4. واردکردن توکن ربات و اطلاعات مدیر
5. تنظیم وب‌هوک تلگرام
6. فعال‌سازی Mini App
7. اجرای ربات و بررسی عملکرد آن

برای جزئیات نصب، فایل "install.sh" و تنظیمات پروژه را بررسی کنید.
